# Favqulodda Holatlar - Doctor A 🚑🚨

Ushbu loyiha klinikada yuz berishi mumkin bo'lgan favqulodda holatlar (shoshilinch tibbiy holat, agressiya, yong'in) yuzaga kelganida tibbiyot xodimlarining harakat qilish algoritmlarini jamlovchi zamonaviy va interaktiv **One-Page (Bir sahifali)** veb-saytdir.

Loyihaning dizayni ilg'or Web-texnologiyalar va **Glassmorphism** uslubidan foydalanib yaratilgan. 

## 📌 Kodlar va Ularning Ma'nolari

Sayt uchta asosiy xavf signali algoritmlariga asoslangan:

*   🔵 **KO'K KOD (Blue Code)** — Tibbiy shoshilinch holat (Bemor hushsizligi, yurak yoki nafas to'xtashi). Jamoaviy yondashuv, BLS (bazaviy reanimatsiya) va ACLS (kengaytirilgan reanimatsiya) tadbirlari algoritmi.
*   ⚪ **OQ KOD (White Code)** — Jismoniy agressiya, og'zaki tahdidlar va xodimlar/bemorlar xavfsizligiga tahdid. Nizoni deeskalatsiya qilish va xavfsizlik choralarini ko'rish algoritmi.
*   🔴 **QIZIL KOD (Red Code)** — Yong'in xavfsizligi. Muolajalarni to'xtatish, bemorlarni evakuatsiya qilish va yong'inni lokalizatsiya qilish tartibi.

## 🛠️ Texnologiyalar

Ushbu loyiha quyidagi texnologiyalar asosida qurilgan:
*   **HTML5:** Semantik va tushunarli struktura.
*   **CSS3 (Vanilla):** Dinamik fon, tranzaksiyalar, *Glassmorphism* uslubi.
*   **JavaScript:** Bo'limlar o'rtasida sahifa yangilanmasdan o'tish (SPA mantiq) va mavzuga mos ranglar o'zgarishi.
*   **Font Awesome:** Tushunarli va chiroyli piktogrammalar (ikonalar).
*   **Google Fonts:** Zamonaviy 'Inter' shrifti.

## 🚀 Qanday Ishlatiladi?

1. Loyihani yuklab oling yoki `git clone` orqali nusxalang:
   ```bash
   git clone https://github.com/GeneralAXTED/Favqulodda-holatlar-Doctor-A.git
   ```
2. Loyiha papkasini oching:
   ```bash
   cd Favqulodda-holatlar-Doctor-A
   ```
3. `index.html` faylini istalgan zamonaviy veb-brauzer orqali oching. Hech qanday qo'shimcha server o'rnatish talab etilmaydi!

## 📸 Skrinshotlar va Dizayn 
Saytning o'ziga xosligi shundaki, har bir "Kod" bo'limiga o'tganingizda, sayt foni va urg'u berilgan detallar o'sha kod rangiga (Ko'k, Oq-Qora, Qizil) moslashadi. Kontent oson o'qiladigan, bo'limlarga ajratilgan kartochkalarda taqdim etilgan.
